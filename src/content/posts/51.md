↑本日的推荐是本人今年的年度梦之曲，如果方便的话请认真听听同时随便看看本文↑

本来 2024 年从中秋开始一个月我的安排是这样的：

``` 
中秋：成都 -> 九月底：美国 -> 十一：南京参加夏娜婚礼+黑龙江小兴安岭 -> 珠海出差+周末广州游 -> 十月二十：日本福冈看小乐队 Chilli Beans. 演唱会 
```

结果却几乎无缝地遭遇了各种各样的事故而变成了下面这样，中间还被不好在这说的支线剧情打了个措手不及进一步消耗了精神：

```
中秋：成都 -> 来不及办签证所以没法去美国 -> 放假前一天摔坏了折叠屏手机，花了快一万换新 -> 去南京第一天被逆天大雨淋了个透 -> 去黑龙江玩倒是除了累和不小心扭了脚腕以外没出什么大事 -> 支线剧情开始，同时得知租房要被没收的百年难得一遇倒霉事 -> 明明不用上班但是因为接近力竭而只觉得累的珠海出差 -> 广州见到了群友很开心 -> 回来抽空看房但没啥好房决定搬进公租房 -> 出发福冈前一天得知行程最重要的 live 被取消，但是机票已经来不及取消了 -> 为了填补 live 的空档去了熊本看花火大会，但在熊本再次被大雨淋爆，回程还被卡在电车上一个小时差点回不了酒店 -> 回来后一边要准备签房搬家一边得了重感冒，终于在搬家当天遭遇台风+发烧三重打击 -> 以至于搬家后一直没精力收拾房子
```

在浑浑噩噩地过了意外频出的整整一个月，没有留下任何记忆点反而精疲力尽之后，总算，总算！迎来了我本年度第四趟日本旅行！！（明明是第四次却是流水账 2？等我有空再写 1.5 吧）

本次旅行属于是我日本单人游的集大成之作，整个行程张弛有度，从行前准备到突发情况全都处理得游刃有余，既避开了绝大多数人挤人的情况，又完成了美食品鉴、追 live、红叶狩り、圣地巡礼等多项旅游目标，正可谓群友之鉴！回来一看 xhs 发现全在说这几天京都到处人挤人的我只能放生嘲笑我已经比绝大多数 xhs 博主要会玩了www

这次出行是在几个月前我抽中 10.22 的 muque 1st oneman live tour @Nagoya 的时候决定的，当时只确定要来名古屋看 live，时间临近的时候发现 10.21 有我上个月错过的 Chilli Beans. live 的名古屋场没卖完的票，而十月底的时间点也正是日本仅次于樱花季的旅游季——红叶季，那么我的行程确定成了：10.21/22 在名古屋看 live，10.23/24 在京都红叶狩り，10.25 再返程。我的老天爷啊，连看两个我今年最爱的乐队，就算其他时间玩的再烂我也得爽死了吧！！！而这次运气终于到了我这边，其他时间玩的也非常完美。

## 行前准备

与之前几次不同的是，红叶季的京都酒店价格非常恐怖连普通三星都要1000/晚起步，迫使我不得不稍微违反个人原则提前规划一下行程。于是这次首次尝试用 Notion 做详细的路书，让我这个从来不喜欢做笔记、上大学以来就没做过笔记的人都惊叹于自己竟然能做的这么好！得益于 Notion 丰富的功能，可以美观地布局的同时自由地嵌入图片、地图甚至 pdf，几乎可以把一切出发前的准备全都一股脑塞进来。

![](https://s2.loli.net/2024/11/28/vCpxTbK2y3Srwgt.png)

![](https://s2.loli.net/2024/11/28/tL8PR9nxm7E1UBS.png)

有兴趣参考我行程或路书模板的可以直接点击 <https://openkiri.notion.site/1414ad79654c80eb9295f3ee1f31b0b6?pvs=4>。

去京都除了悠闲地欣赏红叶以外还要做一下《四叠半神话大系》和《春宵苦短，少女前进吧》这两部神作的圣地巡礼，所以在行程里我还加入了游客相对比较少的下鸭三角洲/下鸭神社/吉田寮/京都大学。

除了酒店和 live 要预订以外，岚山小火车トロッコ和保津川漂流在旅游旺季也需要提前预订，前者甚至早就被黄牛订光而只能上某鱼购买黄牛票（后面会讲到并不怎么推荐小火车），其他行程就随机应变就好了不用卡时间。

我们公司有每年必须至少休掉 5 天法定年假的规定（准确的说天数与工作年份相关），所以这一趟我难得大方地一口气请了两天半的假狠狠爽一把！

日本 live 演出中肯定是不让拍的，总之真是圆了我今年的第一个梦！！Chilli Beans. 是我在 24 年过年期间粉上的第一个乐队，三个女生用自己的方式自由地用各种风格演绎摇滚，不说每首歌都有或多或少的风格差异完全是模板化的反义词，单是一首歌里就会糅杂各种各样的风格和元素，特别是不拘泥于明显的正歌-副歌的段落感，而是在一首歌的不同位置融入不同的感情，从头听到尾会非常非常的舒畅！（原谅我没有任何音乐基础只会用自己方式描述）出道也才五年不到，但是为海贼王唱了时隔十七年的新片尾曲（她们也是尾田最喜欢的乐队之一），在今年年初实现了登上武道馆，非常了不起！

上个月主唱 Mono 因病取消了演出，今天虽然发挥说不上很稳定，但看她开始恢复精神了就很开心！几千人一起喊どうしようママ的场面真是难绷又开心。最后的安可后 MC，Mono 一边坐着像闲话家常一样说着自己最近开始能好好吃饭了之类的事情，Lily 在旁边静静地弹着吉他，Mono 说完 Maika 也接着跟观众唠嗑，然后就这么静静地唱了《fu uh》，感觉时间就算停在这一刻也无所谓了。散场的时候几个人里 Mono 殿后退场，就在要走到台后一步之遥的时候突然停了下来把话筒放在了桌上，像是忘记了什么东西一样站着背过身去，结果突然跳着转身做了一个发射爱心的动作，真的可爱死了！！！

还有什么比得上看美少女蹦蹦跳跳玩摇滚呢！！

我大概是今年四月份开始接触 muque，在 youtube 给我推了 [my crush 的 MV](https://www.youtube.com/watch?v=33tITqSwGB8) 之后我一开始的感想是“好可爱的歌啊”，但就没有继续去搜他们其他的歌。过了一两周之后，youtube 又一次给我推了 [my crush 的 Live 录像](https://www.youtube.com/watch?v=Sl5m8XNObNY)，这次我是被狠狠地击中了。好可爱的主唱！好有活力的乐队成员！好有感染力的现场！！于是又去听了 bite you 和 desert.，彻底被 muque 吸引当即决定一定得看一次 Live。

而从十月 muque 的第一张完整专辑《Dungeon》发布以来，听《Dungeon》午睡成了我治愈十月力竭的精神的慰藉，这样的中午一定是从《Teardrops In The Sea》开始的，也就是本文最上面播放器里的这首。恰到好处的巧合，今天的 Live 也是从《Teardrops In The Sea》开场的，当乐队成员随着前奏入场，あさくら开口的一瞬间，我仿佛就跟在做梦一样，脑子飘飘忽忽得疯狂分泌多巴胺，十月以来遭遇的一切都已经不再重要，此时此刻，就在此地，我的灵魂想在名为 muque 的火焰中摇曳到燃尽。接着的《Dear, my friends》和《456》都是以あさくら为中心的抒情曲，没有很多的互动，灯光也很克制，气氛被拉到顶点。然后！！！灯光一转亮堂，欢快的《feelin'》开始，在あさくら唱着“Yeah Yeah Yeah”站到前线高台挥手的时刻，全场都沸腾地一起挥舞着手，这场梦正式开始了高潮并且一直高潮到了结尾。有时是《escape》或《(T)LAST ME》悲伤的旋律，有时是《bite you》张狂的呼喊，有时是《my crush》俏皮的可爱，あさくら饱含感情的声音，takachi 激情宣泄的 solo 鼓点，Kenichi 和 Lenon 的吉他贝斯遥相对峙，一切在写到这里的时候都还像是鲜明得不想褪色的蓝玛瑙色的梦。

首先尝一下酒店早餐，来之前我都没有想到日本竟然是个没有早餐文化的国家，所谓日本传统早餐其实也就是古时有钱人才吃得起的正餐，所以酒店的自助早餐也就是自助茶泡饭和自助荞麦面，味道还行。

第一次来日本乡下，不出意外地果然体验到了意外，锹山神社作为乡下的小城市，虽然距离 JR 车站单程只有十分钟，然而只能乘间隔几小时的巴士来回，更要命的是巴士会随时延误，Google Maps 上的时刻表并不会像电车一样时刻更新，我从下午一点参观完准备搭车去漂流开始等1：03的巴士，结果等到了一点二十都不见车影，此时距离漂流只有不到40分钟了，而即使巴士现在立马到站等我坐到 JR 站也还需要走预计十几分钟的路到漂流出发点。于是我当即立断去 xhs 搜了一下龟冈的出租车电话，头一次体验用电话在日本打车，从没系统学过的蹩脚日语和尽量说的简单的幼儿英语并用，成功让接线员听懂了我现在在锹山神社他们会派一辆出租车在十分钟内来接我。结果上除了花 80 坐了 3.5km 略显奢侈以外，顺利让我在 1：45 的时候到达了保津川漂流起点，真是可喜可贺！

![](https://s2.loli.net/2024/11/30/2ORrM5GJz9ZWBtc.jpg)

接下来就是我超享受的两个小时悠闲漂流了！！说是漂流，但其实与国内会弄湿全身的刺激的漂流完全是两个东西，在整整两个小时里，小船会顺着和缓的水流一路向下，你只需要放松心情欣赏两岸层林浸染的岚山风景，听三位船夫轮流吹牛打屁，偶尔会路过几段稍微有点狭窄的湍流带来一点点点的小刺激，偶尔会路过几只白鹭、猴子、鹿之类的同样在惬意度日的动物，偶尔会有电车或トロッコ小火车从头顶或旁边驶过，船上和车上的人还会互相挥手打招呼。全程我拍了恐怕有几百张的图和录像，这里稍微少放一点。

回程就得再次经过唯一一个人巨多但又无法避开的地方：京都站。特别是周日晚上饭点的京都站，除了人好多都找不到能吃饭的店以及伊势丹的无限自动扶梯好厉害以外没有留下其他的记忆，最后吃了一碗咖喱乌冬面，咖喱很足很不错，吃完面不够的话还有免费的饭可以拌上咖喱当咖喱饭吃。不过建议还是在别的地方吃完饭再来京都站坐车。
